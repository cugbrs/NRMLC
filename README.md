# NRMLC-A-Noise-Robust-Multilabel-Remote-Sensing-Scene-Classification-Framework
Multi-label remote sensing scene classification (MLRSSC) aims to assign multiple semantic labels to complex highresolution scenes. Although exhaustive expert annotation enables accurate supervision, its high cost limits large-scale applications. Low-cost labels from crowdsourcing, existing geographic products, or weak annotation pipelines provide a scalable alternative, but they often contain missing and false-positive labels. Such noisy supervision, together with object-scale variation and severe label imbalance, makes high-precision ML-RSSC challenging. To address this issue, we propose NRMLC, a noise-robust framework for learning from low-cost noisy annotations. NRMLC first constructs multi-scale scene representations through a MultiScale Feature Extraction (MSFE) module to preserve objects at different spatial scales. A Label-Wise Enhanced Attention (LWEA) module then converts these representations into labelspecific attention maps and class-wise feature embeddings, alleviating the bias caused by sparse positive labels. The resulting embeddings are processed by a Transformer-Based Multi-Label Classification (TBMC) module to model label dependencies and generate dependency-aware prediction probabilities. During optimization, a Multi-Label Self-Adaptive Training (MLSAT) strategy dynamically updates soft targets to reduce the influence of missing and false-positive annotations.
